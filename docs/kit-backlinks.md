# Kit backlinks — Gentle Wagers

Objectif : faire pointer des liens vers `https://gentlewagers.com/` depuis des
sites à forte autorité, pour accélérer l'indexation et remonter sur les
recherches « paris entre amis » / « bet with friends ».

**Règle d'or** : quelques publications sincères et contextuelles valent mieux
que du spam de masse. Google pénalise les schémas de liens artificiels, et les
forums bannissent vite les comptes « pub ».

---

## 1. Ce qui est déjà fait automatiquement (Hermes)

- Google Search Console : propriété vérifiée + sitemap soumis.
- IndexNow : Bing/Yandex/Seznam prévenus (script `scripts/indexnow.sh`).
- Sitemap + canonical + hreflang FR/EN sur le site.
- Métadonnées GitHub du dépôt : **bloqué** (le jeton de l'app n'a pas le droit
  « Administration »). À faire à la main en 30 s ou en accordant le droit :
  GitHub → Settings → Integrations → GitHub App → Bet_with_friend → Administration.

## 4. Conseils de publication

1. **Compte réel** : complète le profil, poste 2-3 messages hors pub avant de
   partager — sinon suppression quasi certaine.
2. **Un seul lien** par publication, dans le corps du texte (pas de mur de liens).
3. **Réponds aux commentaires** : les fils actifs remontent, et Google voit du trafic.
4. **Espace les publications** (2-3 par semaine max) : naturel > volume.
